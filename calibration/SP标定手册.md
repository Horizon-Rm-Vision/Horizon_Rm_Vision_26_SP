该程序集实现了一套完整的相机-云台系统标定流程，包括**相机内参标定**、**手眼标定（相机与云台之间的变换）**以及**数据采集**工具。下面详细说明标定流程和启动方法。

---

## 1. 准备工作

### 1.1 硬件准备
- **棋盘格标定板**：打印一张棋盘格，测量方格的实际边长（单位mm），并数清内角点行列数（例如11×8）。
- **相机与云台**：确保相机和云台（带IMU）已正确连接并能被程序识别。
- **配置文件**：编辑 `calibration.yaml`，填入正确的参数：
  - `pattern_cols`、`pattern_rows`：内角点列数、行数。
  - `center_distance_mm`：方格边长（mm）。
  - `R_gimbal2imubody`：云台坐标系到IMU本体系的旋转矩阵（通常为3x3单位阵，除非已知安装偏差）。
  - 相机参数：`camera_name`、`exposure_ms`、`gain`、`vid_pid`（根据实际相机修改）。
  - 云台串口：`com_port`（如 `/dev/ttyUSB1`）等通信参数（若使用CAN，则配置 `can_interface` 等）。

### 1.2 编译程序
假设项目使用CMake，进入根目录执行：
```bash
mkdir build && cd build
cmake ..
make
```
生成的可执行文件通常位于 `build/` 下。

---

## 2. 数据采集（capture）

**目的**：采集不同姿态下棋盘格的图像以及对应的IMU四元数，用于后续手眼标定。

### 2.1 运行采集程序
```bash
./capture configs/calibration.yaml -o assets/img_with_q
```
- 第一个参数是配置文件路径（`configs/calibration.yaml`）。
- `-o` 指定输出文件夹（默认为 `assets/img_with_q`），程序会自动创建。

### 2.2 采集操作
- 程序启动后，实时显示相机画面，并叠加：
  - 从IMU四元数解算出的欧拉角（用于判断IMU坐标系方向及零漂）。
  - 棋盘格角点检测结果（仅用于预览，不保存亚像素坐标）。
- **按键功能**：
  - `s`：保存当前图像和对应的四元数。
    - 图像保存为 `{输出文件夹}/N.jpg`
    - 四元数保存为 `{输出文件夹}/N.txt`（格式：`w x y z`，每行一个四元数）
  - `q`：退出程序。
- 尽量让云台运动到不同角度（覆盖各种姿态），每按一次 `s` 保存一组数据。建议采集10组以上。

> **注意**：确保拍摄时棋盘格清晰、角点检测成功（画面上会画出角点）。

---

## 3. 相机内参标定（calibrate_camera）

**目的**：获得相机的内参矩阵和畸变系数，用于后续solvePnP计算。

### 3.1 准备图片
- 可使用采集到的图片（或另外拍摄一组专门用于标定的图片），将图片放入一个文件夹（如 `assets/calib_imgs`）。
- 图片命名格式：`1.jpg`, `2.jpg`, ...（程序按序号递增读取）。

### 3.2 运行标定程序
```bash
./calibrate_camera assets/calib_imgs -c configs/calibration.yaml
```
- 第一个参数是图片文件夹路径。
- `-c` 指定配置文件（用于读取棋盘格尺寸）。

### 3.3 标定过程
- 程序逐张读取图片，检测角点并显示（按任意键继续）。
- 若检测成功，则将该帧数据加入标定集。
- 全部图片处理完后，计算相机内参，并将结果以YAML格式输出到终端。

### 3.4 更新配置文件
将终端输出的 `camera_matrix` 和 `distort_coeffs` 复制到 `calibration.yaml` 中（新增或覆盖对应字段），以便后续手眼标定使用。

---

## 4. 手眼标定（calibrate_handeye）

**目的**：计算相机坐标系到云台坐标系的变换矩阵 `R_camera2gimbal` 和 `t_camera2gimbal`。

### 4.1 准备数据
- 确保采集的图片和四元数位于同一文件夹（如 `assets/img_with_q`），且配置文件已包含正确的相机内参。

### 4.2 运行手眼标定
```bash
./calibrate_handeye assets/img_with_q -c configs/calibration.yaml
```
- 第一个参数是包含 `N.jpg` 和 `N.txt` 的文件夹路径。
- `-c` 指定配置文件。

### 4.3 标定过程
- 程序逐组读取图片和四元数：
  1. 从四元数计算云台在世界坐标系下的旋转矩阵 `R_gimbal2world`（基于 `R_gimbal2imubody` 和IMU姿态）。
  2. 通过 `solvePnP` 计算相机到棋盘格的外参（`rvec`, `tvec`）。
  3. 在图像上显示云台欧拉角（用于验证 `R_gimbal2imubody` 是否正确）。
- 按任意键查看下一组。
- 所有数据处理完后，调用 `calibrateHandEye` 求解手眼变换矩阵，并输出结果YAML。

### 4.4 输出解读
输出内容包括：
- 重用的 `R_gimbal2imubody`。
- `R_camera2gimbal` 和 `t_camera2gimbal`（平移量已转换为米）。
- 相机相对于理想安装位置的偏角（yaw/pitch/roll），用于评估安装误差。

将输出的 `R_camera2gimbal` 和 `t_camera2gimbal` 保存，后续可用于云台相机系统。

## 5. 可选：机器人世界手眼标定（calibrate_robotworld_handeye）

**用途**：如果世界坐标系固定（如机器人基座），且标定板在世界中位置固定，可使用此程序同时计算相机到云台和世界到标定板的变换。

### 5.1 与普通手眼标定的区别
- 这里假设世界坐标系是固定的，云台运动但世界系不变。
- 输入仍为图片和四元数，但内部构造的 `R_world2gimbal` 是 `R_gimbal2world` 的转置。
- 调用 `calibrateRobotWorldHandEye` 得到 `R_gimbal2camera` 和 `t_gimbal2camera`，以及世界到标定板的变换。

运行命令与普通手眼类似：
```bash
./calibrate_robotworld_handeye assets/img_with_q -c configs/calibration.yaml
```

输出额外包含标定板到世界原点的距离和偏角。

## 6. 辅助工具：split_video

**用途**：若已录制视频（.avi）和同步的IMU数据（.txt），可用此工具截取指定帧范围，生成新的视频和文本文件。

### 6.1 运行方式
```bash
./split_video -s 100 -e 500 -p output_path input_path
```
- `-s` 起始帧索引（从0开始）
- `-e` 结束帧索引（若缺省则处理到末尾）
- `-p` 输出文件前缀（例如 `records/Big/2024-05-14_11-6-26`，程序会生成 `.avi` 和 `.txt`）
- 最后一个参数 `input_path` 是输入文件前缀（同样不含扩展名）

程序逐帧读取，显示画面，按 `q` 可提前退出。

## 7. 标定流程总结

| 步骤   | 程序                         | 输入              | 输出            | 关键点                  |
| ------ | ---------------------------- | ----------------- | --------------- | ----------------------- |
| 1      | capture                      | 配置文件          | 图片+四元数文件 | 手动按s保存不同姿态数据 |
| 2      | calibrate_camera             | 图片文件夹        | 相机内参YAML    | 将内参写入配置文件      |
| 3      | calibrate_handeye            | 图片+四元数文件夹 | 手眼变换矩阵    | 验证IMU方向正确         |
| (可选) | calibrate_robotworld_handeye | 同上              | 手眼+世界变换   | 适用于固定世界坐标系    |

> **注意**：`R_gimbal2imubody` 的准确性直接影响手眼标定结果。若不确定，可先设为3x3单位阵，标定完成后根据输出的偏角评估是否需要修正。

## 8. 常见问题

### Q: 采集时棋盘格检测失败怎么办？
- 调整光照，确保棋盘格清晰。
- 检查配置文件中的 `pattern_cols` 和 `pattern_rows` 是否正确（内角点数，不是格子数）。
- 可临时修改程序，使用 `cv::findChessboardCorners` 的 `CALIB_CB_FAST_CHECK` 标志提高速度（已默认？）。

### Q: 手眼标定结果不合理？
- 检查 `R_gimbal2imubody` 是否与IMU实际安装方向一致。
- 确保相机内参正确。
- 采集数据时应覆盖足够大的姿态范围，避免退化运动。

### Q: 如何验证标定结果？
- 可用标定后的参数进行投影，计算重投影误差。
- 也可在云台运动时，根据IMU推算的云台姿态和相机观测到的棋盘格位置，验证一致性。
